HBO MAX SKIN - STREAMING BOX INSTALLATION
==========================================

STEP 1: UPLOAD TO GITHUB
-------------------------
1. Go to https://github.com/new
2. Name: kodi-repo
3. Make it PUBLIC
4. Create repository

5. Upload these files to GitHub:
   - addons.xml
   - addons.xml.md5
   - zips/ (folder)
   - repository.hbomax/ (folder)

6. Edit repository.hbomax/addon.xml
   Replace "YOURUSERNAME" with your GitHub username

7. Edit addons.xml
   Replace "YOURUSERNAME" with your GitHub username

8. Re-zip repository:
   cd repository.hbomax
   zip -r ../zips/repository.hbomax/repository.hbomax-1.0.0.zip .

9. Upload changes to GitHub


STEP 2: INSTALL ON STREAMING BOX
---------------------------------

Method A - Add Source (Easiest):

1. Kodi > Settings > File Manager
2. Add source
3. Enter: https://raw.githubusercontent.com/YOURUSERNAME/kodi-repo/main/zips/repository.hbomax/
   (Replace YOURUSERNAME!)
4. Name: HBO Max Repo
5. OK

6. Settings > Add-ons > Install from zip file
7. Select "HBO Max Repo"
8. Select repository.hbomax-1.0.0.zip
9. Wait for notification

10. Settings > Add-ons > Install from repository
11. HBO Max Repository > Look and feel > Skin
12. HBO Max > Install

13. Settings > Interface > Skin > HBO Max
14. Done!


Method B - Direct Download:

1. Download: https://github.com/YOURUSERNAME/kodi-repo/raw/main/zips/repository.hbomax/repository.hbomax-1.0.0.zip
2. Transfer to streaming box (USB/network)
3. Kodi > Settings > Add-ons > Install from zip
4. Browse to zip file
5. Install
6. Then follow steps 10-14 above

TROUBLESHOOTING:
----------------
- Make sure GitHub repo is PUBLIC
- Replace YOURUSERNAME with your actual username
- Check internet connection on streaming box
- Enable "Unknown sources" in Kodi settings if needed
